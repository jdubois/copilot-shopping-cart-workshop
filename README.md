# GitHub Copilot App Java workshop

A small Java shopping-cart template for learning GitHub Copilot App through
hands-on bug fixes, features, UI improvements and runtime investigation.

**[Follow the workshop →](https://www.julien-dubois.com/github-copilot-app-java-workshop/)**

Start with the website's setup chapter to create your own repository from this
template. The starter is intentionally unfinished and uses synthetic data only.

Maintainers: [site publishing and validation](workshop/docs/publishing.md).
